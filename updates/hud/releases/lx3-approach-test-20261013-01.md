# LX3 감속 시험본 / 2026-10-13

이 배포는 검토 ZIP이 아니라 기존 HUD 업데이트기가 적용할 수 있는 서명된 Python6파일 시험본입니다.
감속4파일 + 자동진단2파일이며 실제 Params는 변경하지 않습니다.
별도 정차 설치 도구는 설정 설명 JSON1파일을 추가로 적용합니다. HUD만으로 해당 설명 파일은 바뀌지 않습니다.

## 시험 순서

1. P·속도0·제어 비활성에서 파일/차종/설치 상태 확인 후 설치·재부팅합니다. 현재 기기가 마지막 확인 설치본과 다르면 중단하며 해시 검사를 우회하지 않습니다.
2. 첫 자연 운행: 부드러운 접근ON·강도40/40/40/40, 시간거리·연비/완만/일반/고속 모드 유지, 저속 거리완화OFF. 브레이크를 기다리며 시험하지 말고 평소대로 운전합니다.
3. 기록을 확인한 다음, 정차 후 타력60/접근여유80/감속60/정체60만 변경하고 같은 조건을 비교합니다. 기본TF·jerk·레이더 설정을 동시에 바꾸지 않습니다.
4. 저속 거리완화는 그 뒤 별도로 검토합니다. 처음부터 켜지 않으며 이동 시간거리 목표80%는 실제 전체 간격80%를 뜻하지 않습니다.

앞차 상대속도·감속, 거리/기본 목표/추가 여유, 양의 가속 상한, 목표/실제 가속·jerk, 운전자 브레이크 개입을 rlog와 비교합니다.
자연운행에서 깜빡이와 동측 물체 감지를 포착하면 진동 관련 후보창을 함께 보존합니다. 실제 경고/모터반응으로 단정하지 않습니다.

## 배포/설치 한계

기존 추가 LX3 fb6d3f3f의 검증된 10/12 SPI설치+진단sequence6 파일을 before로 고정했습니다.
sequence7을 먼저 설치했다면 두 진단 파일의 before가 달라 중단됩니다. 이 경우 실제 파일 확인 후 재묶음이 필요합니다.
소스 OTA sequence8은6파일만 포함합니다. root carrot_settings.json은 기존 allowlist밖이라 별도 서명·P검사 설치로 준비했습니다. allowlist/updater/boot 코드는 수정하지 않습니다.
기존 source boot transaction의 일부 실패→6파일 원복을 실제 로컬 파일에서 검증했습니다. 전체검사15개 및 새 정차 설치 활성화 함수 실패복구4개 PASS.
Windows symlink 표시는 모의 검사, systemd/실차 preflight/시간/재부팅/하드웨어 호출은 모의입니다. 실기기 설치 검사로 표현하지 않습니다.
별도 설명 JSON은 HUD 자동 롤백 범위 밖입니다. 감속 원복 후 설명도 맞추려면 서명된 catalog-original을 정차 복구해야 합니다.
Panda/H7·MDPS·조향·모델·DBC/schema·OS·DisableDM·부저/진동 명령은 변경하지 않습니다. 새 native 빌드는 필요 없습니다.
OEM 조향경고·SPI 증가·실제 진동은 미해결입니다. Claude Fable5.1/high의 새 요청은 사용량한도로 완료하지 못했으며 검토 PASS가 아닙니다.
차량 설치/재부팅/도로효과 확인은 아직 없습니다. 보호 중인 기존기기와 EV9에는 이 배포를 적용하지 않습니다.

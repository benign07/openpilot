LX3 legacy clone longitudinal approach overlay — 2026-10-11

Problem and behavior
The deployed legacy LX3 clone has independent mode, following-time, radar,
MPC cost and Hyundai jerk policies. This optional overlay requests earlier
positive-acceleration reduction and a bounded radar-lead comfort margin, and
conditionally increases low-speed jerk/previous-acceleration-change costs.
It does not replace the legacy control-authority, MDPS or lateral paths.

Settings and interactions
ApproachComfortEnabled: LX3 openpilot-long ACC only. OFF is the original
calculation. Invalid/stale radar, pedal override, reset/soft hold, force-decel,
model lane-change start/finish and blended mode exclude the modifier.
ApproachCoastStrength: lowers the existing positive acceleration ceiling
after legacy mode/curve limits. A zero ceiling does not guarantee physical
coasting on every grade. Existing negative ceilings are never relaxed.
ApproachBrakeMargin: adds up to0.5s speed-dependent soft-reference headroom
above legacy dynamic/deceleration TF, with no additional margin above a
combined2.5s target. It does not clip a preexisting baseTF above2.5s. Rise0.1s/s,
release0.08s/s. These are additional-margin rates, not a bound on the sum of
all independent legacy TF changes. The separate legacy TF policies can overlap.
ApproachStopSmooth: up to1.5x both jerk and previous-acceleration-change costs
only during a mild low-speed well-spaced approach. At strength40 max1.2x.
Keeps the existing mode/personality base factor; this is a cost preference,
not an actuator jerk limit or forced brake release. Threat/strong braking
remove the extra multiplier. DynamicTF can still favor agile departure.
ApproachTrafficCalm: up to50percent lower positive acceleration ceiling for
nearby slow traffic below~22km/h. Uses max with approach reduction, not the
sum. Auto Safe mode and lower legacy acceleration curves can compound it.

Other settings
Global modes1Eco/.9,2Safe/.8,3Normal/1,4High/1.2 change acceleration limits.
Eco/Safe also scale comfortBrake and base TF; TF is clipped to configured
gap range, so a mode name is not a promise of longer following distance.
Safe and longitudinal personality also affect base jerk costs. High suppresses
software trafficState. Automatic mode can select Safe/Normal by congestion.
RadarReactionFactor shapes aLeadTau prediction; it does not directly filter
the raw aLeadK cue used by this helper in this legacy version. RadarLatFactor
affects lead selection. radarState distances are processed; legacy leadTwo
can already have a deliberate distance offset. Keep these settings fixed for
the first comparison. LateralTorqueFriction and LatMpcJerkCost are steering
settings, not longitudinal smoothness; this LX3 uses the angle controller.
StopDistanceCarrot, StoppingAccel/hold, longitudinal PID and actuator delay
are retained. Plan changes can feed back through legacy deceleration TF;
unchanged TF policy does not imply all ON/OFF TF values are identical.

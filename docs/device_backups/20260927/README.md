## 복원 기준

이 백업 브랜치의 커밋을 별도 디렉터리에 체크아웃하고 `manifest.json`의 SHA-256으로 파일을 대조합니다. Git LFS가 관리하는 기존 모델은 별도로 받아야 합니다. Linux의 파일 권한은 manifest와 기존 Git 모드를 확인합니다. 조각 파일은 이 버전의 기존 모델 준비 과정과 함께 사용합니다.

설정을 자동 덮어쓰거나 주행 제어 프로세스를 자동 재시작하는 스크립트는 포함하지 않았습니다. 실제 복원은 P단 주차·제어 해제 상태에서 기존 경로를 보존한 뒤 진행합니다.
